本政策說明應用程式「echor」（以下稱「本應用程式」）如何取得、使用及儲存資訊。本應用程式的營運者為個人事業「dannpen」（以下稱「營運者」）。

適用版本

本政策以本應用程式 2.0.0 以上版本的處理方式為基準撰寫。2.0.0 之前的版本有以下不同之處。

  • 沒有付費方案（echor+），也未使用 RevenueCat。不處理與購買相關的資訊。
  • 沒有小工具、出處及多個小花園的功能。
  • 在判定為需徵得同意地區（EU/EEA 等）的裝置上，Firebase Analytics 在使用者許可之前不會進行收集；在其他裝置上，若過去未確認存在明確的拒絕，Firebase Analytics 可能會被啟用。
  • Firebase Crashlytics 不分地區皆有使用。沒有依裝置的區域而不啟動 Firebase 的機制（「4.」），也沒有針對判定為中國大陸之裝置的處理方式（Annex A）。
  • 設定檔的取得（「4.」）不分地區皆會進行。

將本應用程式更新至 2.0.0 以上版本後，即適用本政策所記載的處理方式。

1. 本應用程式處理的資訊

本應用程式可能會處理以下資訊。

使用者輸入或選擇的資訊

  • 文字（備忘錄）的內容、出處
  • 筆記的內容
  • 小花園（彙整文字的單位）的名稱及構成
  • 建立日期與時間、更新日期與時間
  • 與文字或筆記相關的資料
  • 進行備份及還原時由使用者選擇的檔案（檔案內容不會傳送給營運者）

與應用程式設定相關的資訊

  • 通知的開啟／關閉、通知時間
  • 新手引導的完成狀態
  • 小工具顯示的內容及設定（儲存於裝置內的共用區域）
  • 其他應用程式內設定

與付費方案（echor+）購買相關的資訊（2.0.0 以上版本）

  • 購買及訂閱的狀態（已加入的方案、有效期限、是否自動續訂、免費試用的使用情形等）、與 App Store 交易相關的資訊
  • 為管理購買而建立、以裝置為單位的匿名識別碼（刪除並重新安裝本應用程式後，將變為新的識別碼）
  • 與裝置及應用程式相關的技術資訊（OS 及其版本、裝置型號、應用程式版本、語言設定、App Store 的國家、同一提供者的應用程式共用的裝置識別碼（IDFV）等）
  • 隨通訊而傳來的 IP 位址

與使用狀況及當機相關的資訊

  • 透過「4. 關於外部服務」中的 Firebase Analytics 及 Firebase Crashlytics 取得的資訊

本應用程式不會為了管理購買而取得姓名、電子郵件地址或電話號碼。付款所使用的卡號等付款資訊由 Apple 處理，本應用程式及營運者均不會取得。本應用程式不使用廣告用識別碼（IDFA），也不會請求其使用許可（App Tracking Transparency）。此外，本應用程式不會顯示廣告。

2. 資訊的使用目的

本應用程式會依資訊的種類，基於以下目的處理資訊。

  • 儲存及顯示文字、筆記、出處及小花園，提供通知、小工具、備份及還原功能，維持應用程式內設定
  • 確認付費方案的購買、回復及免費試用，管理訂閱狀態（2.0.0 以上版本）
  • 改善應用程式品質、掌握使用狀況、分析及修正問題、維持服務穩定運作（透過 Firebase 取得的資訊）
  • 回覆聯絡事項

本應用程式不會將使用者輸入的文字或筆記內容，用於廣告、使用狀況分析、品質改善或問題分析的目的。

3. 資料儲存

  • 使用者輸入的文字、筆記、出處、小花園及設定資訊，主要儲存在使用者自己的裝置內。為了在小工具中顯示，其中一部分也會儲存在裝置內的共用區域。
  • 目前，本應用程式不會將文字或筆記的內容傳送或儲存至由營運者管理的伺服器。
  • 使用備份功能時，文字、筆記、出處、小花園等資料會匯出為 JSON 格式的檔案，並儲存至使用者選擇的儲存位置或分享對象。使用還原功能時，本應用程式會在裝置內讀取使用者選擇的備份檔案。為處理而建立的暫存副本，會在讀取後刪除。本應用程式不會將備份檔案及其內容傳送或儲存至由營運者管理的伺服器。
  • 若選擇 iCloud Drive 或其他外部服務作為儲存位置或分享對象，該服務對資訊的處理將適用各服務提供者的使用條款及隱私權政策。

4. 關於外部服務

Firebase Analytics・Firebase Crashlytics（Google）

本應用程式為改善品質及分析使用狀況，使用 Firebase Analytics 及 Firebase Crashlytics。本應用程式 2.0.0 以上版本在判定為中國大陸的裝置上不會啟動 Firebase（Annex A）。此外，2.0.0 以上版本會在啟動時確認裝置的區域（地區設定）。在判定為 EU/EEA 等本應用程式視為「需徵得同意地區」之地區的裝置上，通常不會啟動 Firebase（Analytics・Crashlytics）。曾經如此判定的裝置，即使之後變更裝置的區域，通常仍會維持不啟動 Firebase 的狀態。

關於 Firebase Analytics

  • 在 2.0.0 以上版本中，在判定為需徵得同意地區的裝置上，通常不會透過 Firebase Analytics 進行收集，也不會顯示許可或拒絕的確認畫面。即使先前曾經許可，亦同。應用程式內的設定畫面會顯示此裝置上並未進行使用狀況分析，並可取消先前的許可。
  • 在 2.0.0 以上版本中，在會啟動 Firebase 的裝置上，Firebase Analytics 在使用者許可之前不會進行收集。初次使用時會顯示許可或拒絕的確認畫面，僅在選擇「允許」時才開始收集。即使不許可，也可以使用所有功能。許可之後，也可以隨時從應用程式內設定畫面的「使用情況分析」撤回，亦可再次許可。若在先前的版本中已選擇許可或拒絕，將沿用該選擇。另外，Firebase Crashlytics 的使用獨立於 Analytics 的許可或拒絕（見下文）。在判定是否屬於需徵得同意地區時，本應用程式於實作上使用裝置的區域（地區設定），而非應用程式的語言設定。此判定並不能確定使用者的法定居住地。
  • 可能收集的資訊：由 Google 推算之大致（國家／地區層級左右）的地理位置資訊／裝置及應用程式執行個體的識別碼／應用程式內的操作內容／畫面及功能的使用狀況／其他使用狀況資料／OS 資訊、裝置類型、應用程式版本／在預先固定的範圍內彙整的應用程式使用指標
  • 在 Firebase（GA4）資源中，使用者層級及事件層級的資料保留期限設定為 14 個月。使用者層級的資料設定為在記錄到新活動時重設保留期限。另外，Google 方面的彙整報表等可能適用另一套保留規則，並非所有 Analytics 資料都會在 14 個月後刪除。

關於 Firebase Crashlytics

  • 在會啟動 Firebase 的裝置上（在 2.0.0 以上版本中，判定為中國大陸的裝置，以及判定為需徵得同意地區的裝置除外。2.0.0 之前的版本則不分地區皆有使用），Crashlytics 獨立於 Analytics 的許可或拒絕設定，用於取得當機及品質、穩定性相關的診斷資訊。本應用程式不會為 Crashlytics 設定自訂使用者識別碼。傳送至 Crashlytics 的自訂金鑰及記錄，僅限於預先決定的營運相關資訊，不會刻意傳送文字或筆記的內容及其他自由輸入的文字。但是，當機的發生狀況、診斷資訊、與裝置及應用程式相關的資訊等，仍可能被處理。
  • 2.0.0 之前版本的本應用程式，並未依裝置的區域停止 Firebase。因此，裝置內可能殘留由先前版本建立、尚未傳送的當機資訊。
    • 在判定為需徵得同意地區的裝置上，由於本應用程式通常不會啟動 Firebase，通常不會傳送此資訊。本應用程式不會從裝置中刪除此資訊，但刪除應用程式時，此資訊會與裝置內的資料一併刪除。
    • 在 2.0.0 以上版本首次啟動時未被判定為需徵得同意地區的裝置上，啟動 Firebase 時可能會傳送此資訊。
    • 先前版本已傳送的資訊，不適用本說明。
  • 根據 Firebase 官方說明，當機的堆疊追蹤及相關識別碼於取得後保留 90 天，其後開始刪除。此外，本應用程式目前刻意啟用 Crash Insights 功能。透過此功能，為進行匿名化、彙整形式的當機趨勢分析，可能會與使用 Firebase 之其他應用程式的當機資訊進行比較。

共通事項

  • 本應用程式不會將姓名、電子郵件地址等可直接識別個人的資訊傳送給 Firebase。
  • 本應用程式不會將文字的內容、筆記的內容、備份檔案的內容、檔案名稱、URI 及儲存位置的路徑，傳送至 Firebase Analytics 或 Firebase Crashlytics。此外，本應用程式不會將本應用程式的使用者 ID 設定為 Firebase Analytics 的 user_id 或 Firebase Crashlytics 的自訂使用者識別碼。
  • Google 隱私權政策：https://policies.google.com/privacy

RevenueCat（購買及訂閱狀態的管理。2.0.0 以上版本）

本應用程式為確認付費方案的購買、回復及免費試用，以及管理訂閱狀態，使用 RevenueCat, Inc.（美國。以下稱「RevenueCat」）的服務。RevenueCat 受營運者委託，處理以下資訊。

  • 以裝置為單位的匿名識別碼、購買及訂閱的狀態與交易相關資訊、與裝置及應用程式相關的技術資訊（包含 IDFV）
  • 隨通訊而傳來的 IP 位址

本應用程式不會將文字或筆記的內容、姓名、電子郵件地址、電話號碼傳送給 RevenueCat。營運者不會設定本應用程式專屬的使用者 ID，而是使用 RevenueCat 建立的匿名識別碼。

關於 RevenueCat，根據營運者從 RevenueCat 取得之回覆的事項如下。

  • 傳送至 RevenueCat 的資訊儲存於美國。
  • RevenueCat 收到的 IP 位址不會儲存於顧客設定檔中。至於顧客設定檔以外的記錄、中繼資料等，保留期限依資訊種類及處理系統而異，RevenueCat 並未提出固定的最長保留期限。
  • 裝置識別碼（IDFV）若包含在 RevenueCat 的營運用請求記錄中，將在該記錄中保留最長 60 天。
  • 一旦開始與 RevenueCat 通訊，在本應用程式結束之前，RevenueCat 的機制可能會持續通訊。無法中途停止通訊，也無法捨棄尚未傳送的資料。
  • 本應用程式在使用 RevenueCat 之前，會確認 App Store 的國家或地區、裝置的地區設定等。在部分地區（Annex A：中國大陸），在使用者同意之前不會使用 RevenueCat。

關於保留期限及刪除的範圍，請參閱「9. 資料的刪除與使用者的權利」及「10. 保留期限」。RevenueCat 隱私權政策：https://www.revenuecat.com/privacy

Apple（App Store）

付費方案的購買、付款、取消、退款及購買記錄，由 Apple 透過 App Store 處理。Apple 對這些資訊的處理，依 Apple 的隱私權政策。Apple 隱私權政策：https://www.apple.com/jp/legal/privacy/

設定檔的取得（營運者的網站）

本應用程式可能會在啟動時等時機，從營運者的網站（echor.dannpen.com）取得用於應用程式更新通知等的設定檔。取得時，本應用程式不會傳送識別碼或使用者資訊。但是，基於網站的營運，可能會記錄通訊來源的 IP 位址等一般通訊所附帶的資訊。在 2.0.0 以上版本中，判定為中國大陸的裝置不會進行此取得。

網站流量分析

營運者的網站為了解頁面瀏覽量及流量來源趨勢，使用 Cloudflare Web Analytics。根據 Cloudflare 官方說明，Cloudflare Web Analytics 不會收集或使用訪客的個人資料，也不會使用 Cookie、localStorage 等用戶端狀態來衡量使用情況。Cloudflare 隱私權政策：https://www.cloudflare.com/privacypolicy/

意見與建議表單

開啟本應用程式的「意見與建議」時，會在瀏覽器中開啟 Google 表單。在表單中輸入的內容，會透過 Google 的服務傳送給營運者。輸入內容的處理，依「13. 透過聯絡、資訊登記等方式取得的資訊」。

5. 關於通知

本應用程式使用本機通知功能。

  • 通知中可能會顯示使用者儲存的文字（備忘錄）內容的一部分或全部。
  • 這些通知可能會顯示在裝置的鎖定畫面或通知中心。
  • 使用者可自行透過裝置設定或應用程式內設定關閉通知。

6. 關於 AI 與機器學習

  • 目前，本應用程式不會將使用者輸入的文字或筆記內容用於 AI 訓練或機器學習。此外，目前不會將文字或筆記的內容傳送至外部 AI 服務。
  • 若未來新增 AI 相關功能，將修訂本政策並進行必要的告知。

7. 關於向第三方提供及委託

除依法令規定的情形外，營運者不會將使用者輸入的文字或筆記內容提供給第三方。營運者會將所記載範圍內之資訊的處理，委託給「4. 關於外部服務」中所記載的服務提供者（Google、RevenueCat、Cloudflare 等），或使用其服務。

8. 資訊安全

本應用程式將致力採取適當的安全措施，以防止未經授權的存取、資訊外洩、竄改等情形。但是，並不保證完全的安全性。

9. 資料的刪除與使用者的權利

  • 儲存在本應用程式中的文字及筆記，使用者可自行操作刪除。一般而言，從裝置刪除本應用程式後，儲存在裝置內的資料也會一併刪除。但是，從本應用程式匯出的備份檔案，以及儲存在「檔案」App、iCloud Drive 或其他儲存位置的檔案，即使刪除本應用程式也不會自動刪除。不再需要的檔案，請由使用者自行刪除。

即使刪除本應用程式，已傳送至 RevenueCat 等外部服務的資訊，以及由 Apple 管理的購買記錄，也不會自動刪除。此外，刪除應用程式並不會取消訂閱。

依適用的法令，使用者可能可以就自身的資訊請求揭露、更正、停止使用、刪除等。這些請求透過「15. 營運者與聯絡方式」所記載的電子郵件地址受理。處理請求時，我們可能會詢問確認本人身分及特定對象資訊所需的資訊。

11. 致歐洲經濟區（EEA）／法國等地區的使用者

關於歐洲經濟區（EEA）及包含法國在內之地區的使用者，請留意以下事項。

  • 在 2.0.0 以上版本中，在判定為需徵得同意地區的裝置上，本應用程式通常不會啟動 Firebase（Analytics・Crashlytics）（「4.」）。若在其他裝置上許可 Analytics，該同意可隨時撤回。撤回不影響撤回前所進行之處理的合法性。
  • 依適用的資料保護法令，使用者可能就自身的資訊享有存取、更正、刪除、限制處理、異議、資料可攜等權利。

  • 上述權利的行使，透過「15. 營運者與聯絡方式」所記載的電子郵件地址受理。關於本政策的一般問題，也可以透過應用程式內的「意見與建議」傳送。

Annex A — 致中國大陸的使用者（2.0.0 以上版本）

在判定為中國大陸的裝置上，本應用程式會如下運作。判定係依據 App Store 的國家或地區，或裝置的地區設定等進行。

  1. 不會啟動 Firebase（Analytics・Crashlytics）。
  2. 不會從營運者的網站取得設定檔。
  3. 僅在使用者於畫面上同意的情形下，才會為了確認付費方案的購買、回復及免費試用而使用 RevenueCat。在同意之前、不同意時，以及取消同意後重新啟動時，不會初始化 RevenueCat。
  4. 即使未同意，可透過此裝置之 App Store 購買記錄確認的付費方案購買，仍會反映。即使不同意，也可以使用所有免費功能。
  5. 同意可隨時從應用程式的設定畫面取消。取消後，本應用程式不會向 RevenueCat 發出新的查詢。但是，在應用程式啟動期間，RevenueCat 的機制可能會持續通訊。取消同意後再次同意時，裝置內殘留的未傳送資料可能會被傳送。
  6. 所傳送的資訊、儲存位置及保留期限，如「4.」「10.」所述。
  7. 有關個人資訊的聯絡，以及揭露、刪除等請求，透過「15. 營運者與聯絡方式」所記載的窗口受理。
