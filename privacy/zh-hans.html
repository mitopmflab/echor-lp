本政策说明应用“echor”（以下称“本应用”）对信息的获取、使用及保存。本应用的运营者为个体经营者“dannpen”（以下称“运营者”）。

适用版本

本政策以本应用 2.0.0 及以后版本的处理方式为准进行说明。在 2.0.0 之前的版本中，以下几点有所不同。

  • 没有付费方案（echor+），也不使用 RevenueCat。不处理与购买相关的信息。
  • 没有小组件、出处及多个庭院的功能。
  • 对于被判定属于需征得同意的地区（EU/EEA 等）的设备，在用户允许之前，Firebase Analytics 不进行收集；对于其他设备，如果过去未确认到明确拒绝，Firebase Analytics 可能会被启用。
  • 无论地区如何，均使用 Firebase Crashlytics。没有根据设备的区域而不启动 Firebase 的机制（“4.”），也没有针对被判定为中国大陆的设备的处理方式（Annex A）。
  • 无论地区如何，均会获取配置文件（“4.”）。

将本应用更新到 2.0.0 及以后版本后，即适用本政策所述的处理方式。

1. 本应用处理的信息

本应用可能处理以下信息。

用户输入或选择的信息

  • 文字（备忘录）的正文、出处
  • 笔记的正文
  • 庭院（汇集文字的单位）的名称和构成
  • 创建日期时间、更新日期时间
  • 与文字或笔记相关的数据
  • 进行备份及恢复时用户选择的文件（文件内容不会发送给运营者）

与应用设置相关的信息

  • 通知的开/关、通知时间
  • 引导流程的完成状态
  • 小组件显示的内容和设置（保存在设备内的共享区域）
  • 其他应用内设置

与购买付费方案（echor+）相关的信息（2.0.0 及以后版本）

  • 购买与订阅的状态（已加入的方案、有效期限、是否自动续订、是否使用免费试用等）、与 App Store 交易相关的信息
  • 为管理购买而生成的、每台设备各自的匿名标识符（删除并重新安装本应用后，将变为新的标识符）
  • 与设备和应用相关的技术信息（OS 及其版本、设备型号、应用版本、语言设置、App Store 的国家、同一开发者的应用之间共用的设备标识符（IDFV）等）
  • 随通信传送的 IP 地址

与使用情况和崩溃相关的信息

  • 通过“4. 关于外部服务”中的 Firebase Analytics 和 Firebase Crashlytics 获取的信息

本应用不会为管理购买而获取姓名、电子邮件地址或电话号码。用于付款的卡号等支付信息由 Apple 处理，本应用及运营者不会获取。本应用不使用用于广告目的的标识符（IDFA），也不会请求其使用许可（App Tracking Transparency）。此外，本应用不显示广告。

2. 信息的使用目的

本应用根据信息的种类，出于以下目的进行处理。

  • 文字、笔记、出处、庭院的保存及显示，提供通知、小组件、备份及恢复功能，维持应用内设置
  • 确认付费方案的购买、恢复及免费试用，管理订阅状态（2.0.0 及以后版本）
  • 改善应用质量、了解使用情况、分析及修复故障、稳定地运营服务（通过 Firebase 获取的信息）
  • 回复咨询

本应用不会将用户输入的文字或笔记的内容用于广告、使用情况分析、质量改善或故障分析的目的。

3. 关于数据的保存

  • 用户输入的文字、笔记、出处、庭院及设置信息，主要保存在用户自己的设备内。为了在小组件中显示，其中一部分也会保存在设备内的共享区域。
  • 目前，本应用不会将文字或笔记的正文发送或保存至运营者管理的服务器。
  • 使用备份功能时，文字、笔记、出处、庭院等数据将以 JSON 格式的文件导出，并保存至用户选择的保存位置或共享位置。使用恢复功能时，本应用会在设备内读取用户选择的备份文件。为处理而创建的临时副本，会在读取后删除。本应用不会将备份文件及其内容发送或保存至运营者管理的服务器。
  • 如果选择 iCloud Drive 或其他外部服务作为保存位置或共享位置，该服务中对信息的处理适用各服务提供者的条款和隐私政策。

4. 关于外部服务

Firebase Analytics、Firebase Crashlytics（Google）

本应用为改善质量及分析使用情况，使用 Firebase Analytics 和 Firebase Crashlytics。在本应用 2.0.0 及以后版本中，对于被判定为中国大陆的设备，不会启动 Firebase（Annex A）。此外，在 2.0.0 及以后版本中，本应用会在启动时确认设备的区域（地区设置）。对于被判定属于 EU/EEA 等、本应用视为“需征得同意的地区”的地区的设备，通常不会启动 Firebase（Analytics、Crashlytics）。一旦设备被如此判定，即使之后更改了设备的区域，通常也会继续保持不启动 Firebase 的状态。

关于 Firebase Analytics

  • 在 2.0.0 及以后版本中，对于被判定属于需征得同意的地区的设备，通常不会通过 Firebase Analytics 进行收集，也不会显示允许或拒绝的确认。即使以前曾经允许，也同样如此。应用内的设置画面会显示此设备未进行使用情况分析，并可撤回以前的允许。
  • 在 2.0.0 及以后版本中，对于启动 Firebase 的设备，在用户允许之前，Firebase Analytics 不会进行收集。首次使用时会显示允许或拒绝的确认，仅在选择“允许”的情况下才开始收集。即使不允许，也可以使用所有功能。允许之后，也可以随时在应用内设置画面的“使用情况分析”中撤回，并可再次允许。如果在以前的版本中已选择允许或拒绝，将沿用该选择。另外，Firebase Crashlytics 的使用独立于 Analytics 的允许或拒绝（见下文）。在判定是否属于需征得同意的地区时，在实现上使用的是设备的区域（地区设置），而不是应用的语言设置。此判定并不确定用户的法定居住地。
  • 可能收集的信息：由 Google 推算的大致（国家或地区级别）地理位置信息／设备及应用实例的标识符／应用内的操作内容／画面和功能的使用情况／其他使用情况数据／OS 信息、设备类型、应用版本／在预先固定的范围内汇总的应用使用指标
  • 在 Firebase（GA4）媒体资源中，用户级别及事件级别数据的保留期限设定为14个月。对于用户级别的数据，设定为记录到新活动时重置保留期限。另外，Google 方面的汇总报告等可能适用其他保留规则，并非所有 Analytics 数据都会在14个月后删除。

关于 Firebase Crashlytics

  • 在启动 Firebase 的设备（在 2.0.0 及以后版本中，被判定为中国大陆的设备以及被判定属于需征得同意的地区的设备除外。在 2.0.0 之前的版本中，无论地区如何均使用）上，Crashlytics 独立于 Analytics 的允许或拒绝设置，用于获取与崩溃以及质量和稳定性相关的诊断信息。本应用未在 Crashlytics 中设置自定义用户标识符。发送至 Crashlytics 的自定义键和日志仅限于预先确定的运营相关信息，不会有意发送文字或笔记的正文及其他自由输入的文本。但是，崩溃的发生情况、诊断信息、与设备和应用相关的信息等可能会被处理。
  • 2.0.0 之前版本的本应用并未根据设备的区域停止 Firebase。因此，设备内可能残留以前版本创建的、尚未发送的崩溃信息。
    • 对于被判定属于需征得同意的地区的设备，由于本应用通常不会启动 Firebase，因此通常不会发送这些信息。本应用不会从设备中删除这些信息，但删除应用后，这些信息会与设备内的数据一同被删除。
    • 对于在 2.0.0 及以后版本首次启动时未被判定属于需征得同意的地区的设备，在启动 Firebase 时，这些信息可能会被发送。
    • 以前版本已经发送的信息不适用本说明。
  • 根据 Firebase 的官方说明，崩溃的堆栈跟踪及相关标识符自获取起保留90天，之后开始删除。此外，本应用目前有意启用了 Crash Insights 功能。通过此功能，为了以匿名化、汇总的形式分析崩溃趋势，可能会与使用 Firebase 的其他应用的崩溃信息进行比较。

通用

  • 本应用不会将姓名、电子邮件地址等可直接识别个人的信息发送给 Firebase。
  • 本应用不会将文字的正文、笔记的正文、备份文件的内容、文件名、URI 及保存位置的路径发送至 Firebase Analytics 或 Firebase Crashlytics。此外，本应用不会将本应用的用户 ID 设置为 Firebase Analytics 的 user_id 或 Firebase Crashlytics 的自定义用户标识符。
  • Google 的隐私政策：https://policies.google.com/privacy

RevenueCat（管理购买与订阅状态。2.0.0 及以后版本）

为确认付费方案的购买、恢复及免费试用，并管理订阅状态，本应用使用 RevenueCat, Inc.（美国。以下称“RevenueCat”）的服务。RevenueCat 受运营者委托，处理以下信息。

  • 每台设备各自的匿名标识符、购买与订阅的状态及与交易相关的信息、与设备和应用相关的技术信息（包括 IDFV）
  • 随通信传送的 IP 地址

本应用不会向 RevenueCat 发送文字或笔记的正文、姓名、电子邮件地址或电话号码。运营者不设置本应用自己的用户 ID，而是使用 RevenueCat 生成的匿名标识符。

关于 RevenueCat，基于运营者从 RevenueCat 获得的答复的事项如下。

  • 发送给 RevenueCat 的信息保存在美国。
  • RevenueCat 收到的 IP 地址不会保存在客户档案中。对于客户档案以外的日志、元数据等，保留期限因信息种类和处理系统而异，RevenueCat 未提出固定的最长保留期限。
  • 设备标识符（IDFV）如包含在 RevenueCat 的运营性请求日志中，将在该日志中最长保留60天。
  • 与 RevenueCat 的通信一旦开始，在本应用退出之前，RevenueCat 的机制可能会继续通信。无法中途停止通信，也无法丢弃尚未发送的数据。
  • 本应用在使用 RevenueCat 之前，会确认 App Store 的国家或地区、设备的地区设置等。在部分地区（Annex A：中国大陆），在用户同意之前，不会使用 RevenueCat。

关于保留期限及删除的范围，请参阅“9. 数据的删除与用户的权利”及“10. 保留期限”。RevenueCat 的隐私政策：https://www.revenuecat.com/privacy

Apple（App Store）

付费方案的购买、付款、取消、退款及购买记录由 Apple 通过 App Store 处理。Apple 对这些信息的处理依据 Apple 的隐私政策。Apple 的隐私政策：https://www.apple.com/jp/legal/privacy/

获取配置文件（运营者的网站）

本应用可能会在启动时等情况下，从运营者的网站（echor.dannpen.com）获取用于应用更新通知等的配置文件。进行此获取时，本应用不会发送标识符或用户信息。但是，出于网站运营的需要，可能会记录通信来源的 IP 地址等随通常通信产生的信息。在 2.0.0 及以后版本中，对于被判定为中国大陆的设备，不会进行此获取。

网站访问分析

运营者的网站为了解页面浏览量和访问来源的趋势，使用 Cloudflare Web Analytics。根据 Cloudflare 的官方说明，Cloudflare Web Analytics 不收集或使用访问者的个人数据，也不使用 Cookie、localStorage 等客户端状态来衡量使用情况。Cloudflare 的隐私政策：https://www.cloudflare.com/privacypolicy/

意见与建议表单

打开本应用的“意见与建议”后，会在浏览器中打开 Google 表单。在表单中输入的内容将通过 Google 的服务发送给运营者。输入内容的处理依据“13. 通过咨询、通知登记等获取的信息”。

5. 关于通知

本应用使用本地通知功能。

  • 通知中可能会显示用户保存的文字（备忘录）正文的部分或全部内容。
  • 这些通知可能会显示在设备的锁定屏幕或通知中心。
  • 用户可自行通过设备设置或应用内设置关闭通知。

6. 关于 AI 与机器学习

  • 目前，本应用不会将用户输入的文字或笔记的内容用于 AI 的训练或机器学习。此外，目前不会将文字或笔记的内容发送至外部 AI 服务。
  • 将来如果添加与 AI 相关的功能，将修订本政策并进行必要的通知。

7. 关于向第三方提供及委托

除依据法律法规的情形外，运营者不会向第三方提供用户输入的文字或笔记的内容。运营者委托“4. 关于外部服务”中所述的服务提供者（Google、RevenueCat、Cloudflare 等）在所述范围内处理信息，或使用其服务。

8. 安全

本应用致力于采取适当的安全措施，以防止未经授权的访问、信息泄露、篡改等。但是，本应用并不保证绝对安全。

9. 数据的删除与用户的权利

  • 保存在本应用中的文字和笔记，可由用户自行操作删除。通常，从设备中删除本应用后，设备内保存的数据也会被删除。但是，从本应用导出的备份文件，以及保存在“文件”App、iCloud Drive 或其他保存位置的文件，即使删除本应用也不会被自动删除。不再需要的文件，请用户自行删除。

即使删除本应用，已发送至 RevenueCat 等外部服务的信息以及由 Apple 管理的购买记录也不会被自动删除。此外，删除应用并不会取消订阅。

根据适用的法律法规，用户可能有权就自身信息请求披露、更正、停止使用、删除等。上述请求通过“15. 运营者与联系方式”中所列的电子邮件地址受理。在处理时，我们可能会询问确认本人身份及确定相关信息所需的信息。

11. 致 EEA／法国等地区的用户

对于 EEA（欧洲经济区）以及包括法国在内的地区的用户，请留意以下几点。

  • 在 2.0.0 及以后版本中，对于被判定属于需征得同意的地区的设备，本应用通常不会启动 Firebase（Analytics、Crashlytics）（“4.”）。在其他设备上允许 Analytics 的情况下，可随时撤回该同意。撤回不影响撤回前所进行处理的合法性。
  • 根据适用的数据保护法律法规，用户可能就自身信息享有访问、更正、删除、限制处理、反对、数据可携带等权利。
  • 居住在法国的用户，可以向 CNIL（法国国家信息与自由委员会）提出申诉。
  • 上述权利的行使，通过“15. 运营者与联系方式”中所列的电子邮件地址受理。关于本政策的一般性问题，也可以通过应用内的“意见与建议”发送。
  • Google／Firebase、RevenueCat 等服务提供者可能会在日本境外（包括 EEA 以外）处理信息。在境外处理信息的保护措施，因服务提供者、所处理的信息以及适用的合同条件而异。详情请参阅各服务提供者的隐私政策等，或通过“15. 运营者与联系方式”的联系窗口咨询。关于在境外处理的保护措施，RevenueCat 公开了纳入其服务条款的数据处理附录（包括与标准合同条款相关的规定）。Google 就 Firebase Crashlytics 制定了数据处理和安全条款，就 Google Analytics 制定了数据处理条件。RevenueCat 的数据处理附录（https://www.revenuecat.com/dpa）和 Firebase 的数据处理和安全条款（https://firebase.google.com/terms/data-processing-terms）已在各公司的网站上公开。
  • 是否属于需征得同意的地区的判定，依据的是设备的区域（地区设置），并不确定用户的居住地。即使是居住在 EEA 的用户，如果设备的区域不属于需征得同意的地区，且从未被判定属于需征得同意的地区，也可能会进行“4.”中所述的 Firebase Analytics 和 Firebase Crashlytics 的处理。在 2.0.0 及以后版本中，即使在这种情况下，在用户允许之前，Firebase Analytics 也不会进行收集。Firebase Crashlytics 的使用独立于 Analytics 的允许或拒绝（“4.”）。
  • 在 2.0.0 及以后版本中，通过 Firebase Analytics 进行的使用情况分析，以用户的明确同意（在确认画面中选择“允许”，或在设置画面中开启“使用情况分析”）作为法律依据。同意可随时撤回，撤回后不再进行新的收集。
  • 对于崩溃及可靠性相关信息的处理，可能以维持本应用稳定运营及安全的正当利益（legitimate interests）为依据，但这并不意味着同意等其他法律要求因此一律不再需要。

12. 各地区的处理

在部分地区，本应用根据适用的法律法规，调整了对信息的处理。EEA 和法国请参阅“11.”，中国大陆请参阅“Annex A”。

13. 通过咨询、通知登记等获取的信息

运营者可能会通过咨询、各类通知的登记、问卷调查等，获取电子邮件地址、输入内容及用户发送的其他信息。所获取的信息将用于以下目的。

  • 回复咨询
  • 发送各类通知
  • 提供及改善服务
  • 确认需求

所获取的信息不会用于上述以外的目的。

14. 本政策的变更
