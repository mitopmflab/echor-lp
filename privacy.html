本ポリシーでは、アプリ「echor」（以下、「本アプリ」）における情報の取得・利用・保存について説明します。本アプリの運営者は、個人事業「dannpen」（以下、「運営者」）です。

対象となるバージョン

本ポリシーは、本アプリのバージョン 2.0.0 以降の取扱いを基準に記載しています。バージョン 2.0.0 より前のバージョンでは、次の点が異なります。

  • 有料プラン（echor+）はなく、RevenueCat は利用していません。購入に関する情報は扱いません。
  • ウィジェット、出典、複数の箱庭の機能はありません。
  • Firebase Analytics は、同意対象地域（EU/EEA など）と判定した端末では許可するまで収集せず、それ以外の端末では、明示的な拒否が過去に確認されていない場合、有効になることがあります。
  • Firebase Crashlytics は、地域にかかわらず利用しています。端末のリージョンによって Firebase を起動しない仕組み（「4.」）や、中国本土と判定された端末での取扱い（Annex A）はありません。
  • 設定ファイルの取得（「4.」）は、地域にかかわらず行います。

本アプリをバージョン 2.0.0 以降に更新すると、本ポリシーに記載した取扱いが適用されます。

1. 本アプリで扱う情報

本アプリでは、以下の情報を扱う場合があります。

ユーザーが入力または選択する情報

  • ことば（メモ）の本文、出典
  • ノートの本文
  • 箱庭（ことばをまとめる単位）の名前や構成
  • 作成日時、更新日時
  • ことばやノートに関連するデータ
  • バックアップおよび復元の際にユーザーが選択するファイル（ファイルの内容が運営者に送信されることはありません）

アプリ設定に関する情報

  • 通知のON/OFF、通知時刻
  • オンボーディングの完了状態
  • ウィジェットに表示する内容や設定（端末内の共有領域に保存されます）
  • その他のアプリ内設定

有料プラン（echor+）の購入に関する情報（バージョン 2.0.0 以降）

  • 購入・購読の状態（加入しているプラン、有効期限、自動更新の有無、無料体験の利用など）、App Store での取引に関する情報
  • 購入の管理のために作られる、端末ごとの匿名の識別子（本アプリを削除して入れ直すと、新しいものになります）
  • 端末・アプリに関する技術的な情報（OS とそのバージョン、端末のモデル、アプリのバージョン、言語設定、App Store の国、同じ提供元のアプリで共通の端末の識別子（IDFV）など）
  • 通信に伴って届く IP アドレス

利用状況・クラッシュに関する情報

  • 「4. 外部サービスについて」の Firebase Analytics・Firebase Crashlytics を通じて取得される情報

本アプリは、購入の管理のために、氏名、メールアドレス、電話番号を取得しません。支払いに使うカード番号などの支払い情報は Apple が扱い、本アプリおよび運営者は取得しません。本アプリは、広告目的の識別子（IDFA）を利用せず、その利用許可（App Tracking Transparency）も求めません。また、広告を表示しません。

2. 情報の利用目的

本アプリでは、情報の種類に応じて、以下の目的で取り扱います。

  • ことば・ノート・出典・箱庭の保存および表示、通知、ウィジェット、バックアップおよび復元の提供、アプリ内設定の維持
  • 有料プランの購入・復元・無料体験の確認、購読の状態の管理（バージョン 2.0.0 以降）
  • アプリの品質改善、利用状況の把握、不具合の分析・修正、安定したサービス運営（Firebase を通じて取得される情報）
  • お問い合わせへの対応

本アプリは、ユーザーが入力したことばやノートの内容を、広告、利用状況分析、品質改善または不具合分析の目的で利用しません。

3. データの保存について

  • ユーザーが入力したことば、ノート、出典、箱庭および設定情報は、主にユーザー自身の端末内に保存されます。ウィジェットに表示するため、その一部は、端末内の共有領域にも保存されます。
  • 現時点では、本アプリは、ことばやノートの本文を、運営者が管理するサーバーへ送信または保存していません。
  • バックアップ機能を使うと、ことば・ノート・出典・箱庭などのデータが JSON 形式のファイルとして書き出され、ユーザーが選んだ保存先または共有先に保存されます。復元機能を使うと、本アプリは、ユーザーが選んだバックアップファイルを端末内で読み込みます。処理のために作られた一時的なコピーは、読み込みの後に削除されます。本アプリは、バックアップファイルおよびその内容を、運営者が管理するサーバーへ送信または保存しません。
  • iCloud Drive その他の外部サービスを保存先または共有先に選んだ場合、そのサービスにおける情報の取扱いには、各サービス提供者の規約とプライバシーポリシーが適用されます。

4. 外部サービスについて

Firebase Analytics・Firebase Crashlytics（Google）

本アプリでは、品質改善および利用状況の分析のため、Firebase Analytics および Firebase Crashlytics を利用しています。本アプリのバージョン 2.0.0 以降は、中国本土と判定された端末では、Firebase を起動しません（Annex A）。また、バージョン 2.0.0 以降は、起動時に端末のリージョン（地域設定）を確認します。EU/EEA など、本アプリが「同意対象地域」として扱う地域と判定した端末では、通常、Firebase（Analytics・Crashlytics）を起動しません。一度そのように判定した端末では、その後に端末のリージョンを変更しても、通常、Firebase を起動しない状態が続きます。

Firebase Analytics について

  • バージョン 2.0.0 以降、同意対象地域と判定した端末では、通常、Firebase Analytics による収集を行わず、許可・拒否の確認も表示しません。以前に許可していた場合も同様です。アプリ内の設定画面では、この端末で利用状況の分析が行われていないことを表示し、以前の許可を取り消すことができます。
  • バージョン 2.0.0 以降、Firebase を起動する端末では、Firebase Analytics は、ユーザーが許可するまで収集を行いません。初回に許可・拒否の確認を表示し、「許可する」を選んだ場合に限り、収集を開始します。許可しなくても、すべての機能を利用できます。許可した後も、アプリ内の設定画面の「利用状況の分析」から、いつでも撤回でき、再び許可することもできます。以前のバージョンで許可または拒否を選んでいた場合は、その選択を引き継ぎます。なお、Firebase Crashlytics は、Analytics の許可・拒否とは独立して利用します（下記）。同意対象地域に当たるかどうかの判定には、実装上、アプリの言語設定ではなく、端末のリージョン（地域設定）を使います。この判定は、ユーザーの法的な居住地を確定するものではありません。
  • 収集される可能性のある情報：Google が算出する、おおよその（国・地域単位程度の）地理的位置情報／デバイスおよびアプリインスタンスの識別子／アプリ内での操作内容／画面や機能の利用状況／その他の利用状況データ／OS情報・端末種別・アプリバージョン／あらかじめ固定された範囲で集計されるアプリの利用指標
  • Firebase（GA4）のプロパティでは、ユーザーレベルおよびイベントレベルのデータ保持期間を14か月に設定しています。ユーザーレベルのデータについては、新しい活動が記録されると保持期間がリセットされる設定です。なお、Google側の集計レポート等には別の保持ルールが適用される場合があり、すべてのAnalyticsデータが14か月で削除されるものではありません。

Firebase Crashlytics について

  • Crashlytics は、Firebase を起動する端末（バージョン 2.0.0 以降は、中国本土と判定された端末、および同意対象地域と判定された端末を除きます。バージョン 2.0.0 より前のバージョンでは、地域にかかわらず利用しています）で、Analytics の許可・拒否の設定とは独立して、クラッシュおよび品質・安定性に関する診断情報の取得のために利用しています。本アプリは、Crashlytics にカスタムのユーザー識別子を設定していません。Crashlytics に送るカスタムキーやログは、あらかじめ定めた運用上の情報に限っており、ことばやノートの本文その他の自由入力のテキストを意図的に送ることはありません。ただし、クラッシュの発生状況、診断情報、端末・アプリに関する情報等は、処理される場合があります。
  • バージョン 2.0.0 より前の本アプリは、端末のリージョンによって Firebase を止めていませんでした。そのため、以前のバージョンが端末内に作成した、まだ送信されていないクラッシュ情報が残っている場合があります。
    • 同意対象地域と判定した端末では、本アプリは通常 Firebase を起動しないため、通常、これを送信しません。本アプリはこの情報を端末から削除しませんが、アプリを削除すると、端末内のデータとともに削除されます。
    • バージョン 2.0.0 以降の最初の起動時に同意対象地域と判定されなかった端末では、Firebase を起動するときに、この情報が送信されることがあります。
    • 以前のバージョンがすでに送信した情報には、この説明は当てはまりません。
  • Firebase 公式の説明によれば、クラッシュのスタックトレースおよび関連する識別子は、取得から90日間保持された後、削除が始まるとされています。また、本アプリでは現在、Crash Insights の機能を意図的に有効にしています。この機能により、匿名化・集約された形でのクラッシュ傾向の分析のため、Firebase を利用する他のアプリのクラッシュ情報との比較が行われる場合があります。

共通

  • 本アプリは、氏名・メールアドレス等、個人を直接特定できる情報を Firebase に送りません。
  • 本アプリは、ことばの本文、ノートの本文、バックアップファイルの内容、ファイル名、URI および保存先のパスを、Firebase Analytics または Firebase Crashlytics に送りません。また、Firebase Analytics の user_id、または Firebase Crashlytics のカスタムユーザー識別子として、本アプリのユーザーIDを設定しません。
  • Google のプライバシーポリシー：https://policies.google.com/privacy

RevenueCat（購入と購読の状態の管理。バージョン 2.0.0 以降）

本アプリは、有料プランの購入・復元・無料体験の確認と、購読の状態の管理のため、RevenueCat, Inc.（米国。以下、「RevenueCat」）のサービスを利用しています。RevenueCat は、運営者の委託を受けて、次の情報を処理します。

  • 端末ごとの匿名の識別子、購入・購読の状態と取引に関する情報、端末・アプリに関する技術的な情報（IDFV を含みます）
  • 通信に伴って届く IP アドレス

本アプリは、RevenueCat に、ことばやノートの本文、氏名、メールアドレス、電話番号を送りません。運営者は、本アプリ独自のユーザーIDを設定せず、RevenueCat が作る匿名の識別子を使います。

RevenueCat について、運営者が RevenueCat から得た回答に基づく事項は、次のとおりです。

  • RevenueCat に送られた情報は、米国に保存されます。
  • RevenueCat が受け取る IP アドレスは、顧客プロフィールには保存されません。顧客プロフィール以外のログ・メタデータ等については、情報の種類や処理システムにより保持期間が異なり、RevenueCatは固定の最大保持期間を提示していません。
  • 端末の識別子（IDFV）は、RevenueCat の運用上のリクエストログに含まれる場合、そのログに最大60日間保持されます。
  • 一度 RevenueCat との通信が始まった後は、本アプリを終了するまで、RevenueCat の仕組みが通信を続ける場合があります。通信を途中で止めることや、まだ送られていないデータを破棄することは、できません。
  • 本アプリは、RevenueCat を使う前に、App Store の国・地域や端末の地域設定などを確認します。一部の地域（Annex A：中国本土）では、ユーザーが同意するまで、RevenueCat を使いません。

保持期間と削除の範囲は、「9. データの削除と、ユーザーの権利」および「10. 保持期間」をご覧ください。RevenueCat のプライバシーポリシー：https://www.revenuecat.com/privacy

Apple（App Store）

有料プランの購入、支払い、解約、返金、購入の記録は、Apple が App Store を通じて扱います。これらの情報の Apple における取扱いは、Apple のプライバシーポリシーによります。Apple のプライバシーポリシー：https://www.apple.com/jp/legal/privacy/

設定ファイルの取得（運営者のWebサイト）

本アプリは、起動時などに、運営者のWebサイト（echor.dannpen.com）から、アプリの更新のお知らせなどに使う設定ファイルを取得することがあります。この取得のとき、本アプリが、識別子やユーザー情報を送ることはありません。ただし、Webサイトの運営上、通信元の IP アドレスなど、通常の通信に伴う情報が記録されることがあります。バージョン 2.0.0 以降、中国本土と判定された端末では、この取得を行いません。

Webサイトのアクセス解析

運営者のWebサイトでは、ページの閲覧数や流入の傾向を把握するため、Cloudflare Web Analytics を利用します。Cloudflare の公式の説明によれば、Cloudflare Web Analytics は、訪問者の個人データを収集または利用せず、利用状況の計測に Cookie や localStorage 等のクライアント側の状態を使いません。Cloudflare のプライバシーポリシー：https://www.cloudflare.com/privacypolicy/

ご意見・ご要望のフォーム

本アプリの「ご意見・ご要望」を開くと、Google フォームがブラウザで開きます。フォームに入力した内容は、Google のサービスを通じて運営者に送られます。入力した内容の取扱いは、「13. お問い合わせ・案内登録等を通じて取得する情報」によります。

5. 通知について

本アプリでは、ローカル通知の機能を利用しています。

  • 通知には、ユーザーが保存したことば（メモ）の本文の一部または全部が表示される場合があります。
  • これらの通知は、端末のロック画面や通知センターに表示される可能性があります。
  • 通知は、ユーザー自身が、端末の設定またはアプリ内の設定から無効にできます。

6. AI・機械学習について

  • 現在、本アプリでは、ユーザーが入力したことばやノートの内容を、AI の学習や機械学習に利用していません。また、現時点では、ことばやノートの内容を外部の AI サービスへ送っていません。
  • 将来、AI に関する機能を追加する場合は、本ポリシーの改訂と必要なお知らせを行います。

7. 第三者提供・委託について

運営者は、法令に基づく場合を除き、ユーザーが入力したことばやノートの内容を、第三者に提供しません。運営者は、「4. 外部サービスについて」に記載したサービス提供者（Google、RevenueCat、Cloudflare など）に、記載した範囲の情報の処理を委託し、またはそのサービスを利用しています。

8. セキュリティ

本アプリでは、不正アクセス、情報漏えい、改ざん等を防ぐため、適切な安全対策に努めます。ただし、完全な安全性を保証するものではありません。

9. データの削除と、ユーザーの権利

  • 本アプリに保存されたことばやノートは、ユーザー自身の操作で削除できます。通常、アプリを端末から削除すると、端末内に保存されたデータも削除されます。ただし、本アプリから書き出したバックアップファイルや、Files アプリ、iCloud Drive その他の保存先に保存されたファイルは、アプリを削除しても自動では削除されません。不要になったファイルは、ユーザー自身で削除してください。

本アプリを削除しても、RevenueCatなどの外部サービスに送信済みの情報や、Appleが管理する購入記録は自動的には削除されません。また、アプリの削除によってサブスクリプションが解約されることはありません。

適用される法令に基づき、ユーザーは自己の情報について、開示、訂正、利用停止、削除等を請求できる場合があります。これらのご請求は「15. 運営者・お問い合わせ」に記載のメールアドレスで受け付けます。対応にあたっては、本人確認や対象情報の特定に必要な情報をお尋ねする場合があります。

11. EEA／フランスをはじめとする地域のユーザーへ

EEA（欧州経済領域）およびフランスを含む地域のユーザーについては、以下の点にご留意ください。

  • バージョン 2.0.0 以降、同意対象地域と判定された端末では、本アプリは、通常、Firebase（Analytics・Crashlytics）を起動しません（「4.」）。それ以外の端末で Analytics を許可した場合、その同意はいつでも撤回できます。撤回は、撤回の前に行われた処理の適法性には影響しません。
  • 適用されるデータ保護法令に基づき、ユーザーは、自己の情報について、アクセス、訂正、消去、処理の制限、異議、データポータビリティ等の権利を有する場合があります。
